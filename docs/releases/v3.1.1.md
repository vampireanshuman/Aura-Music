**Aura Music 3.1.1** restores one-tap in-app updates (**Download and install**) for Aura release builds and updates release automation to Node 24.

### Fixed
- **In-app updates:** Restored the `com.auramusic.app` release package check in the update center so release builds re-enable automatic update checks and show **Download and install** instead of falling back to **Open on GitHub**.
- **Release APK matching & notes:** Restored matching `Aura-Music` / `Aura` APK assets across multi-APK GitHub releases and parsing `**Aura …**` opening release summaries with Aura branding across the updater sheet.

### Installing
Needs Android 10 or later. Aura Music 3.1.1 installs over any earlier Aura version and keeps your library. *(Users updating from v3.0.0 or v3.1.0 install this update once via GitHub Releases; subsequent releases update directly inside Aura.)*
