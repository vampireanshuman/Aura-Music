# Security Policy

## Supported Versions

Security fixes and patches are actively provided for the latest stable release of **Aura Music**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or vulnerability in Aura Music, please report it privately rather than creating a public issue.

### How to Report
* Submit a private security advisory through the **GitHub Security Advisories** tab on the repository:
  `https://github.com/vampireanshuman/aura-music/security/advisories/new`
* Alternatively, contact the maintainer directly (`@vampireanshuman`).
* Please include:
  * Description of the vulnerability and affected components
  * Steps to reproduce or proof-of-concept code
  * Potential security impact assessment

### Response Timeline
* **Initial acknowledgment:** Within 48 hours.
* **Assessment & mitigation plan:** Within 5 business days.
* **Coordinated patch release:** Deployed promptly upon verification.

Thank you for helping keep Aura Music secure for our community.
